# Глиняный зоопарк 🐾

Фото глиняной фигурки превращается в карточку героя. Карточки копятся в коллекции.
Чистый HTML + CSS + JS, без бэкенда, без ИИ и внешних API. После первой загрузки работает офлайн.

## Перед выкладкой

1. В `data.js` в первой строке `OWNER_GEN` впиши имя в родительном падеже («Сони», «Маши»). Заставка и заголовок покажут «Зоопарк Сони».
2. Когда меняешь любой файл и выкладываешь заново, поменяй `CACHE = 'clay-zoo-v1'` в `sw.js` на `v2`, `v3` и так далее. Иначе телефон может ещё раз показать старую версию.

## Выложить бесплатно (GitHub Pages)

```bash
cd /Users/user/Desktop/SonyaMonsters
git init -b main && git add . && git commit -m "Глиняный зоопарк"
gh repo create clay-zoo --public --source=. --push
gh api -X POST repos/:owner/clay-zoo/pages -f "source[branch]=main" -f "source[path]=/"
```

Или через сайт: создай репозиторий, загрузи файлы, затем Settings → Pages → Branch `main` / `/ (root)`.
Ссылка будет вида `https://ТВОЙ-ЛОГИН.github.io/clay-zoo/`, а заработает через 1–2 минуты.

Альтернатива без аккаунта: перетащи папку на https://app.netlify.com/drop.

## Как открыть на Redmi 14 и добавить на экран

1. Открой ссылку в **Chrome**.
2. Подожди, пока загрузится заставка, и нажми «Поехали!». Так всё сохранится для офлайна.
3. Меню Chrome (три точки) → **«Установить приложение»** или **«Добавить на главный экран»**.
4. На домашнем экране появится иконка «Зоопарк», которая открывается как обычное приложение.

Дай приложению доступ к камере, когда Chrome спросит. Если кнопка «Сфотографировать» не открывает камеру, есть «Выбрать из галереи».

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка всех экранов |
| `styles.css` | Стили, анимации, `prefers-reduced-motion` |
| `data.js` | Имя владелицы, списки имён и суперсил, редкости, генератор |
| `app.js` | IndexedDB, рисование карточки в canvas, экраны, сохранение и шаринг |
| `sw.js` | Офлайн-кэш |
| `manifest.webmanifest`, `icons/` | PWA и иконка |
| `fonts/` | Comfortaa и Nunito (Google Fonts, лежат локально, чтобы работали офлайн) |
